\# Interfaces de Usuario - Caso Mapuescuela (Entrega 2)



Este módulo contiene las interfaces web desarrolladas como evolución de los formularios de Flowable Forms a una solución propia, permitiendo la interacción de los usuarios con el flujo del proceso de negocio.



\## Estructura de Pantallas



1\. \*\*`pantalla1.html` (Datos del Pedido):\*\* Formulario donde el cliente ingresa su información de contacto y selecciona la modalidad de entrega (retiro en tienda o despacho).

2\. \*\*`pantalla2.html` (Pago y Carga de Comprobante):\*\* Vista donde se presenta el N° de pedido generado por el sistema, los datos de la cuenta bancaria para la transferencia y el campo para adjuntar el comprobante de pago.

3\. \*\*`pantalla3.html` (Revisión y Validación):\*\* Panel de uso interno para la emprendedora / voluntario, donde se visualiza el pedido, se revisa el comprobante adjunto y se registra la decisión (aprobación, rechazo o error) con sus respectivas observaciones.



\## Instrucciones de Uso

Para visualizar las pantallas de forma local, abrir directamente cualquiera de los archivos `.html` en cualquier navegador web moderno (Google Chrome, Edge, Firefox).
